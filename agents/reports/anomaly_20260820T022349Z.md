# Elevated Player Bust Rate for aggressive_20 Strategy

- **Pairing:** aggressive_20 vs standard_17
- **Severity:** medium
- **Detected:** 20260820T022349Z

## Evidence
Over 50 rounds: bust=58.0% vs ceiling threshold of 40% (breached by 18 points); win=38.0%, loss=60.0%, push=2.0%. Strategy pairing is aggressive_20 (hits until hand value reaches 20) vs standard_17 dealer strategy.

## Likely cause
The player_strategy in use is AggressivePlayerStrategy ("aggressive_20") in strategies.py, whose should_hit() returns True for any hand value < 20. This forces the player to keep drawing cards even from typically unsafe totals (e.g., 15-19), which in standard blackjack carry a high probability of busting with a single additional card. This is explicitly noted in the code comment as a "deliberately over-aggressive" fixture kept for stress-testing the anomaly monitor, rather than a bug in the dealing/outcome logic. The Table.play_round loop directly honors should_hit's decision with no cap or safety check, so the high bust rate is an expected consequence of this strategy's logic, not an error in Table, Hand, or Deck.

## Recommendation
Confirm this is the intended stress-test fixture behavior rather than a misconfiguration in production strategy assignment. If aggressive_20 is only meant for test/monitor validation, verify it is not being paired against real dealer sessions and exclude this pairing from production alerting, or tag it as a known/expected anomaly. If it was mistakenly enabled in a live table config, replace it with BasicPlayerStrategy ("basic_17") which hits only below 17, and re-run the 50-round sample to confirm bust rate returns under the 40% ceiling.
