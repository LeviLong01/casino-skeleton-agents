# Elevated player bust rate for aggressive_20 vs standard_17 pairing

- **Pairing:** aggressive_20 vs standard_17
- **Severity:** low
- **Detected:** 20260820T020444Z

## Evidence
Over the last 50 rounds for aggressive_20 vs standard_17: win=36.0%, loss=56.0%, push=8.0%, bust=54.0%. The player bust rate of 54.0% breaches the configured ceiling of 40%. This aligns with the strategy's should_hit logic (hand.value() < 20), which forces additional hits on 17-19 totals that a standard strategy (threshold 17) would stand on, mathematically increasing bust likelihood per the Hand.value()/is_bust() logic in casino/hand.py.

## Likely cause
The AggressivePlayerStrategy (name="aggressive_20") in casino/strategies.py intentionally hits until the hand value reaches 20 (should_hit returns True while hand.value() < 20), instead of the standard threshold of 17 used by BasicPlayerStrategy. This is explicitly documented in the code comment as a "deliberately over-aggressive... stress-test fixture" designed to generate anomaly signal. Because the player keeps drawing cards on hand totals of 17, 18, and 19 (all of which would stand under normal basic strategy), the probability of exceeding 21 on each additional draw is high, directly inflating the bust rate. This is expected behavioral output of the fixture, not a bug in the dealing/table logic (Table.play_round, Hand.value, and Deck all behave correctly and consistently with standard blackjack rules).

## Recommendation
No corrective code change is needed to the game engine itself since this is intended fixture behavior. Recommend: (1) Confirm with the monitoring/anomaly-detection team whether aggressive_20 should be excluded from production anomaly alerting or tagged as a known stress-test strategy so it doesn't trigger false-positive incidents. (2) If aggressive_20 is unintentionally enabled in a live/production strategy pool, disable or gate it behind a test-only flag. (3) If the bust-rate ceiling threshold (40%) is meant to apply uniformly, consider parameterizing thresholds per strategy pairing so known-aggressive fixtures have appropriately higher expected bust ceilings, reducing alert noise.
