# Elevated player bust rate for aggressive_20 strategy vs standard_17 dealer

- **Pairing:** aggressive_20 vs standard_17
- **Severity:** low
- **Detected:** 20260819T201004Z

## Evidence
Over 50 rounds: win=36.0%, loss=62.0%, push=2.0%, bust=62.0% for aggressive_20 vs standard_17. The bust rate of 62.0% breaches the monitor's 40% ceiling threshold. Loss rate (62.0%) matches bust rate (62.0%) almost exactly, confirming that nearly all losses are attributable to player busts rather than dealer out-drawing the player.

## Likely cause
The flagged behavior is expected/deterministic given the code, not a genuine anomaly. AggressivePlayerStrategy.should_hit() (casino/strategies.py) instructs the player to keep hitting until hand.value() >= 20, versus the standard basic strategy's threshold of 17. Hitting on hand totals of 17, 18, and 19 (which basic strategy would stand on) sharply increases the probability of drawing a card that pushes the hand over 21, since any 4+ (or any card when total is 18-19) busts. This strategy is explicitly documented in its own docstring as "deliberately over-aggressive... kept in the strategy library as a stress-test fixture so the anomaly monitor has real, occasional signal to react to." The Table.play_round() logic correctly checks player_hand.is_bust() immediately after the player's hit loop and awards the round to the dealer, which is standard blackjack rules being applied correctly to a strategy fixture designed to bust often.

## Recommendation
No code fix needed for a bug — this is the intended stress-test behavior of AggressivePlayerStrategy. Action items: (1) Confirm with the monitor owner whether aggressive_20 vs standard_17 should be excluded/allow-listed from the bust-rate alert threshold, since it's a fixture designed to trigger it. (2) If the monitor should only alert on genuinely anomalous (unexpected) strategy pairings, add a suppression/exception list for known stress-test strategies. (3) Optionally increase the sample size beyond 50 rounds to confirm the observed rate matches the theoretical bust probability for a hit-to-20 policy, ruling out any deck/dealing bug in Table.play_round or Deck.
