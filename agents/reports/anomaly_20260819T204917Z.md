This is explicitly called out in the class docstring as "Deliberately over-aggressive: kept in the strategy library as a stress-test fixture so the anomaly monitor has real, occasional signal to react to." The Table.play_round(), Hand.value()/is_bust(), and Deck logic are all standard and show no bugs — the elevated bust rate is a direct, deterministic consequence of the strategy's hit threshold, not a code fault in dealing, card counting, or ace-handling logic.
