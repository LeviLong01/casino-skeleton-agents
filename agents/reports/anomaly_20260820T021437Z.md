# Elevated player bust rate for aggressive_20 strategy vs standard_17 dealer

- **Pairing:** aggressive_20 vs standard_17
- **Severity:** low
- **Detected:** 20260820T021437Z

## Evidence
Monitor breach: player bust rate 58.0% > ceiling 40%; player win rate 28.0% below expected range floor 30% (range 30%-55%). Sample: 50 rounds, win=28.0%, loss=60.0%, push=12.0%, bust=58.0%. Source confirms AggressivePlayerStrategy.should_hit() returns True while hand.value() < 20, versus the standard/dealer threshold of 17, and the class docstring explicitly flags it as a stress-test fixture designed to trigger anomaly signals.

## Likely cause
The flagged behavior is expected, not a bug. AggressivePlayerStrategy.should_hit() (casino/strategies.py) keeps hitting until hand.value() >= 20, far past the conventional 17 stopping point used by BasicPlayerStrategy and the dealer. Hitting on hands of 12-19 dramatically raises the probability of drawing a card that pushes the total over 21, since roughly 4/13 ranks (10, J, Q, K) plus various card combinations easily bust a hand already in the high teens. This strategy is explicitly documented in the source as "deliberately over-aggressive... kept as a stress-test fixture so the anomaly monitor has real, occasional signal to react to." The observed 58% bust rate and 28% win rate are the natural statistical consequence of this intentionally suboptimal hitting policy, not an engine malfunction, RNG/deck defect, or scoring bug in Hand.value()/is_bust() (which correctly implements soft-ace adjustment and bust detection).

## Recommendation
No engine fix required. Verify this is a known/expected fixture pairing: either (1) add aggressive_20 to an allowlist/exception list in the anomaly monitor config so it doesn't page on-call as a real incident, or (2) if aggressive_20 was mistakenly enabled against real traffic/production tables instead of being confined to test/stress harnesses, disable it there and confirm via config which strategy pairings are meant to run in production. Also confirm sample size (50 rounds) is being tracked separately per strategy pairing to avoid conflating stress-test fixture results with genuine production anomalies.
