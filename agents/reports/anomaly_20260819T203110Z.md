# Elevated player bust rate for aggressive_20 vs standard_17 pairing

- **Pairing:** aggressive_20 vs standard_17
- **Severity:** low
- **Detected:** 20260819T203110Z

## Evidence
Over the last 50 rounds for aggressive_20 vs standard_17: win=32.0%, loss=62.0%, push=6.0%, bust=60.0%. The player bust rate of 60.0% breached the configured ceiling of 40%, while no other component of the play_round/Hand logic shows defects (dealer logic, value calculation, and outcome resolution all follow standard blackjack rules correctly).

## Likely cause
The flagged behavior is expected, not a bug. AggressivePlayerStrategy (name="aggressive_20") in casino/strategies.py deliberately keeps hitting until hand.value() >= 20 (should_hit returns True for any value < 20), instead of stopping at the standard 17 threshold used by BasicPlayerStrategy/StandardDealerStrategy. Since hand.value() in Hand.value() only counts soft aces down when busting, continuing to hit on hands in the 17-19 range with any hard total substantially raises the probability of exceeding 21 before reaching 20, compared to stopping at 17. The class docstring explicitly states it is 'deliberately over-aggressive... kept in the strategy library as a stress-test fixture so the anomaly monitor has real, occasional signal to react to,' confirming this is an intentional test fixture designed to trigger exactly this kind of bust-rate anomaly.

## Recommendation
No code fix required for correctness — this is a known stress-test fixture behaving as designed. Recommend either: (1) excluding aggressive_20 from production anomaly monitoring by adding it to an allow-list/known-fixture exception list so it doesn't page on-call, or (2) if the intent is to validate the monitor's detection capability, close this alert as expected/verified and document that aggressive_20's bust-rate breach confirms the anomaly monitor is functioning correctly. If aggressive_20 is unintentionally deployed against real players/tables, disable or remove it from the active strategy pool used outside of monitor testing.
